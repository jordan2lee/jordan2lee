### Key Contributions - Projects soon to be public (after paper publication)
#### 1. Machine Learning & Predictive Modeling

* [clinical_outomes_lung](https://github.com/EllrottLab/clinical_outcomes_lung) : Machine learning and statistical survival models for predicting clinical outcomes in lung cancer cohorts.
* [lung_targeted_therapy_response](https://github.com/jordan2lee/lung_targeted_therapy_response) : Analysis of genomic and clinical features associated with response to targeted therapies in lung cancer.
* [CNV_predict_subtypes](https://github.com/jordan2lee/CNV_predict_subtypes) : Machine learning approach for predicting cancer subtypes using copy-number variation data.
* [public-gene-expression-ml](https://github.com/jordan2lee/public-gene-expression-ml) : Machine learning workflows for public transcriptomics and gene expression analysis.
* [embedding-experiments](https://github.com/EllrottLab/embedding-experiments) : Comparative experiments and analysis pipelines for evaluating representation quality, transferability, and performance of vector embeddings.
* [imputation-fts](https://github.com/jordan2lee/imputation-fts) : Data imputation and feature engineering pipelines for handling missing data in fine-tuned predictive models.
* [copy_number_variation-feature_importance](https://github.com/jordan2lee/copy-number-variation-feature_importance) : Analysis of feature importance for copy-number variation-based machine learning models.
* [machine-learn-subtypes-hcmi](https://github.com/jordan2lee/machine-learn-subtypes-hcmi) : Machine learning models for predicting cancer subtypes from molecular data.
* [pathology-review-priority](https://github.com/jordan2lee/pathology-review-priority) : Machine learning approach for prioritizing pathology cases for review.

#### 2. Genomics & Bioinformatics

* [multimodal-download](https://github.com/jordan2lee/multimodal-download) : Tools for downloading and organizing multimodal biomedical data across genomic and clinical data types.
* [vcf-WGS](https://github.com/jordan2lee/vcf-WGS) : Workflow and utilities for processing and analyzing whole-genome sequencing variant data in VCF format.
* [WGS-nextflow-workflow](https://github.com/ohsu-cedar-comp-hub/WGS-nextflow-workflow) : Nextflow workflow for processing and analyzing whole-genome sequencing data.
* [alchemist-dna-job](https://github.com/ohsu-comp-bio/alchemist-dna-job) : Workflow components for processing and analyzing cancer DNA sequencing data.
* [hla2vec](https://github.com/EllrottLab/hla2vec) : Machine learning approach for learning vector representations of HLA sequences.
* [HLA_Learner](https://github.com/jordan2lee/HLA_Learner) : Machine learning models for analyzing and predicting HLA-related sequence characteristics.
* [oncogene-finder](https://github.com/jordan2lee/oncogene-finder) : Identifies candidate oncogenes from cancer genomic data.
* [non-smoker-lung-cancer](https://github.com/jordan2lee/non-smoker-lung-cancer) : Genomic analysis of lung cancer in patients who have never smoked.
* [molecular_similarity](https://github.com/jordan2lee/molecular_similarity) : Calculates and analyzes molecular similarity between compounds.
* [liver-cancer-drug-response](https://github.com/jordan2lee/liver-cancer-drug-response) : Analysis and modeling of molecular features associated with drug response in liver cancer.

#### 3. Biomedical Data Engineering & Infrastructure

* [gdc-mirror](https://github.com/EllrottLab/gdc-mirror) : Scalable automated data mirroring and local synchronization tooling for the NCI Genomic Data Commons (GDC).
* [bmeg-etl](https://github.com/bmeg/bmeg-etl) : ETL workflows for integrating biomedical and cancer datasets into a common data model.
* [awg-portal-etl](https://github.com/kellrott/awg-portal-etl) : ETL pipeline for integrating data from the AWG Portal into a standardized data resource.
* [build_graph_db_alchem](https://github.com/jordan2lee/build_graph_db_alchem) : Builds a biomedical graph database from integrated cancer and clinical datasets.
* [clinical_array_gap](https://github.com/jordan2lee/clinical_array_gap) : Tools for identifying and analyzing gaps and missingness in clinical data arrays.
* [data-normalization](https://github.com/jordan2lee/data-normalization) : Methods and utilities for normalizing biomedical and genomic datasets.
* [benchmark_transform_ML_input](https://github.com/jordan2lee/benchmark_transform_ML_input) : Benchmarking and evaluation of data transformations for machine learning inputs.

#### 4. Cancer & Clinical Data Analysis

* [corr-lung-cancer](https://github.com/jordan2lee/corr-lung-cancer) : Analysis of relationships between genomic features and clinical characteristics in lung cancer.
* [ACED-patients-analysis](https://github.com/jordan2lee/ACED-patients-analysis) : Analysis of patient and clinical data from the ACED biomedical data ecosystem.
* [druglit_paper](https://github.com/kellrott/druglit_paper) : Computational analysis supporting research on drug-related biomedical literature.

#### 5. Visualization & Biomedical Applications

* [cancer-viewer-app](https://github.com/jordan2lee/cancer-viewer-app) : Interactive application for exploring and visualizing cancer genomic and clinical data.
* [dashboard-multi](https://github.com/jordan2lee/dashboard-multi) : Interactive dashboard for exploring multiple biomedical datasets and analyses.
* [clustering-viz](https://github.com/jordan2lee/clustering-viz) : Visualization tools for exploring clustering results and high-dimensional biological data.
